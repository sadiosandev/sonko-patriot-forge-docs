# SonkoPatriot Forge

Modern Laravel API Generator for Laravel 13.

SonkoPatriot Forge (SPForge) is a modernized code generator focused on Laravel 13, native PHP attributes, APIs, web scaffolding, authentication, permissions, Data DTOs, Query Builder, DataTables, Excel, Scout, Activitylog and OpenAPI.

## Start here

- Install the package locally or through Composer.
- Publish the configuration.
- Install the optional Web Dashboard/Auth Kit.
- Generate your first API or API + Scaffold module.
